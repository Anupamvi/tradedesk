# Report visual language

Plain GitHub-flavored markdown only. **No HTML.** No `<span>`, `<div>`, `<h1 style>`, or `&nbsp;` in cards. Those tags print as junk in the editor.

Use markdown headings for size (`#` title, `##` sections). Use emoji + **bold** for status. Tables: short cells, no tags inside pipes.

| Meaning | Write this |
|---------|------------|
| CLOSE | **CLOSE** |
| HOLD | **HOLD** |
| ASSESS | **ASSESS** |
| ROLL | **ROLL** |
| In the table | **YES** |
| Scored, not tabled | no |
| Shield | Shield |
| Fire | Fire |
| Spike | Spike |
| Put / Call / Condor | Sell put credit / Sell call credit / Sell iron condor |
| P&L up | +$1,234 |
| P&L down | −$1,234 |

Print order: Expert table, Shock watch, sleeve board. Sleeve board is diagnostics only. Every executable row has **Score** (gates) and **Conf** (naive POP% · book n/a or book win rate).
