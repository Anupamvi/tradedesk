# X sentiment — veto / confirm, never trigger

Two X passes. Do not mix them.

1. **Shock watch (finder)** — **before** the universe is locked. Geo/oil/kinetic only. See `spike.md`. X may put an event on Watch. X may not add a Spike row or pick a strike.
2. **Candidate veto** — **after** the live chain, surviving names + one calendar-regime pass (VIX, 0DTE, Chair, NVDA). Do not scan X to build the Shield/Fire universe.

## Tools

- Shock watch: keyword + semantic for Hormuz, Red Sea, blockade, mine, strike, invasion, missile, oil crash/spike.
- Candidate: ticker + (flow OR sweep OR dark pool OR earnings OR halt). Semantic for crowding on that name.
- Calendar regime: VIX, GEX, 0DTE, Jackson Hole, FOMC, PCE — not Spike.
- If X API is empty, open logged-in x.com via `browser.md`. Do not post. Do not read DMs.

Desk-quality beats influencer screenshots. Vendor GEX/put-wall numbers are **unverified** unless the user attached a file.

## Labels (candidate)

| Label | Meaning | Effect |
|-------|---------|--------|
| Quiet | Little X, no crowd | Confirm or ignore |
| Informed | Specific, dated, structure-aware posts; not a pile-on | Confirm only |
| Crowded | Viral “follow this sweep,” options-lottery chatter, same strike everywhere | **Veto Fire.** Shield only if other gates already passed and size stays at cap |
| Event | Earnings, halt, rumor-as-fact **on that ticker** | **Veto Fire on that ticker.** Index headlines (FOMC, Chair) do not veto single-name Fire. Expiry-overlap still applies |

Headlines and filings use the same labels. A 8-K or genuine halt is Event even if X is Quiet.

## Hard rules

- X never adds a row that failed chain, book, or earnings gates.
- X never copies a printed strike into the table.
- Crowded + Fire = skip, even if the debit looks cheap.
- Crowded + Spike = 0.25% max, no Prime; Crowded + THIN Spike = skip.
- Dark-pool tweets are context, not walls.
- If X tools fail, mark THIN and continue; do not invent sentiment. Spike without X confirm stays THIN and cannot Prime; it still needs the web source.
