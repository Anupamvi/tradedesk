# Source Roles

ORATS owns delayed options analytics and historical research evidence. It never supplies an executable live quote.

Schwab owns current underlying and exact-leg quotes, chains, liquidity, and contract availability. Cultra does not request account, position, balance, transaction, or order data.

Historical strategy evidence, live analytical snapshots, and executable quote snapshots remain separate artifacts with separate timestamps and provenance.

No other local trading pipeline is a data, strategy, model, cache, configuration, or runtime dependency.
