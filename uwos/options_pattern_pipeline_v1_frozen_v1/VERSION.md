# Options Pattern Pipeline V1

This package is the live V1 implementation of the leakage-aware options-pattern
pipeline.

- Version: `options_pattern_pipeline_v1.0`
- CLI: `python3 -m uwos.options_pattern_pipeline_v1`
- Frozen backup package: `uwos/options_pattern_pipeline_v1_frozen_v1/`

The frozen backup is intentionally kept as a restore point. Future changes may
continue in this live package, but the frozen V1 package should stay unchanged
unless the user explicitly asks to refresh the V1 baseline.
